🌴 Coastal Haven Hotel Website

A modern, AI-enhanced hotel website built for coastal regions, designed to showcase luxury, comfort, and local experiences while providing smart, user-friendly interactions for guests.

This project focuses on performance, aesthetics, and intelligent assistance, making it ideal for hotels, resorts, and lodges along the coast.

✨ Features

🏖️ Elegant Coastal UI – Clean, responsive design inspired by ocean and beach aesthetics

🤖 AI-Powered Assistance – Smart guest interactions using Gemini AI (FAQs, recommendations, inquiries)

⚡ Fast & SEO-Friendly – Optimized with Next.js for speed and discoverability

📱 Fully Responsive – Seamless experience across mobile, tablet, and desktop

🎨 Modern Styling – Utility-first styling with Tailwind CSS

🔐 Scalable Architecture – Built with TypeScript for maintainability and future expansion

🧠 AI Capabilities

The website integrates Gemini AI via Genkit to enhance guest experience by enabling:

Automated responses to common guest questions

Personalized recommendations (rooms, amenities, local attractions)

Intelligent content generation for hotel information

This creates a more engaging and interactive experience without requiring constant manual support.

🛠️ Tech Stack
Frontend / UI

TypeScript – Type-safe and scalable development

Next.js – Server-side rendering, routing, and performance optimization

Tailwind CSS – Fast, consistent, and responsive styling

AI Layer

Gemini AI – Natural language understanding and generation

Genkit – AI orchestration and integration

📂 Project Structure
/app        → Next.js app router pages
/components → Reusable UI components
/lib        → AI & utility logic (Genkit, helpers)
/styles     → Global styles and Tailwind config
/public     → Static assets (images, icons)

🚀 Getting Started
Prerequisites

Node.js (v18+ recommended)

npm or yarn

Gemini API access

Installation
git clone https://github.com/zakoshy/coast-hotel.git
cd coastal-hotel-website
npm install

Run Development Server
npm run dev


Open http://localhost:3000 in your browser.
